# Checklist de validação — Fase 3

## Inicialização

- [ ] O menu abre sem erro.
- [ ] A partida inicia.
- [ ] O console não mostra erros.
- [ ] A quantidade de comida muda conforme a qualidade.

## Comida

- [ ] Comida comum aparece.
- [ ] Comida especial dourada aparece.
- [ ] Existem áreas com maior concentração.
- [ ] A comida fica dentro da arena.
- [ ] A comida é reposta após a coleta.
- [ ] A comida próxima é atraída pela cabeça.
- [ ] A coleta acontece apenas perto da cabeça.

## Pontuação e massa

- [ ] Comida comum soma 1 ponto.
- [ ] Comida especial soma 6 pontos.
- [ ] A massa aumenta corretamente.
- [ ] O contador de coletadas aumenta.
- [ ] Reiniciar zera pontuação, massa e coletadas.

## Crescimento

- [ ] A cobra cresce gradualmente.
- [ ] Não surgem vários segmentos de uma vez.
- [ ] O corpo mantém o espaçamento.
- [ ] A cauda continua suave.
- [ ] A espessura aumenta gradualmente.
- [ ] A velocidade diminui apenas levemente.
- [ ] A câmera afasta sem saltos.

## Efeitos

- [ ] A coleta cria partículas.
- [ ] O texto +1 aparece.
- [ ] O texto +6 aparece na comida especial.
- [ ] Os efeitos desaparecem corretamente.
- [ ] Pausar congela os efeitos.

## Desempenho

- [ ] Qualidade baixa permanece estável.
- [ ] Qualidade média permanece estável.
- [ ] Qualidade alta permanece jogável.
- [ ] O pool reutiliza objetos.
- [ ] A comida fora da câmera não é desenhada.
- [ ] O diagnóstico abre com F3 e mostra comidas, pool e efeitos.

## Controles e interface

- [ ] Mouse funciona.
- [ ] Teclado funciona.
- [ ] Toque funciona.
- [ ] Joystick funciona.
- [ ] HUD mostra pontuação.
- [ ] HUD mostra massa.
- [ ] HUD mostra segmentos.
- [ ] HUD mostra coletadas.
- [ ] Pausa e reinício funcionam.
