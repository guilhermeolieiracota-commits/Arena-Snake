# Checklist — Fase 16

## Conta Supabase
- [ ] E-mail inválido mostra mensagem em português.
- [ ] Senha menor que 6 caracteres é rejeitada.
- [ ] Confirmação de senha é obrigatória no cadastro.
- [ ] Senhas diferentes são rejeitadas.
- [ ] Botões ficam bloqueados enquanto a solicitação é processada.
- [ ] Conta nova recebe confirmação por e-mail quando essa opção está ativa.
- [ ] E-mail já cadastrado mostra orientação para entrar ou recuperar senha.
- [ ] O link de confirmação retorna ao endereço do GitHub Pages.

## Fases de 2 minutos
- [ ] A partida inicia em 2:00.
- [ ] O cronômetro chega a 0:00 em 120 segundos de gameplay.
- [ ] Sobreviver conclui a fase e libera a próxima.
- [ ] Morrer mantém a fase atual.
- [ ] A dificuldade aumenta gradualmente.
- [ ] A fase e o cronômetro aparecem no HUD.
- [ ] A maior fase aparece no perfil.

## Encerramento ao sair da tela
- [ ] Trocar de aba encerra a partida.
- [ ] Minimizar o navegador encerra a partida.
- [ ] Bloquear o celular encerra a partida.
- [ ] Sair da PWA encerra a partida.
- [ ] O cronômetro não continua.
- [ ] Bots, alimentos, partículas, controles e áudio são interrompidos.
- [ ] A partida encerrada não concede recompensa.
- [ ] Não existe botão para continuar a tentativa encerrada.

## Crescimento com volume
- [ ] O corpo fica mais grosso conforme a massa aumenta.
- [ ] A cabeça cresce gradualmente.
- [ ] A cauda continua afinando.
- [ ] Colisões acompanham a espessura visual.
- [ ] A câmera se afasta para cobras grandes.
- [ ] Restos neon aceleram comprimento e volume.

## PWA e favicon
- [ ] A aba do navegador mostra a nova imagem.
- [ ] O ícone no iPhone usa a nova imagem.
- [ ] O ícone Android/PWA usa a nova imagem.
- [ ] O ícone maskable não sofre corte importante.
