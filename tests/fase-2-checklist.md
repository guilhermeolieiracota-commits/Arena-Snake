# Checklist de validação — Fase 2

## Inicialização

- [ ] O menu abre sem erros.
- [ ] O Canvas ocupa toda a tela.
- [ ] A partida inicia pelo botão.
- [ ] O console não mostra erros.

## Movimento

- [ ] A cobra anda continuamente.
- [ ] As curvas são suaves.
- [ ] O corpo não treme.
- [ ] O corpo mantém o espaçamento em FPS diferentes.
- [ ] A cauda diminui gradualmente.

## Controles

- [ ] Mouse funciona sem clicar.
- [ ] WASD funciona.
- [ ] Setas funcionam.
- [ ] Seguir o toque funciona.
- [ ] Joystick virtual funciona.
- [ ] Soltar o joystick não trava a cobra.
- [ ] ESC pausa e continua.
- [ ] Botão de pausa funciona.

## Câmera e arena

- [ ] A câmera acompanha suavemente.
- [ ] A grade se move com o mundo.
- [ ] A borda aparece.
- [ ] O aviso de borda funciona.
- [ ] A cobra não sai da arena.
- [ ] Redimensionar não reinicia.

## Qualidade

- [ ] Baixa funciona.
- [ ] Média funciona.
- [ ] Alta funciona.
- [ ] Automática funciona.
- [ ] O diagnóstico abre com D.

## Mobile

- [ ] Não ocorre rolagem durante a partida.
- [ ] Não ocorre zoom acidental.
- [ ] A interface respeita o notch.
- [ ] Vertical funciona.
- [ ] Horizontal funciona.
