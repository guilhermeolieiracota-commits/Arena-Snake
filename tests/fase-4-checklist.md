# Checklist de validação — Fase 4

## Ativação

- [ ] Segurar o botão esquerdo ativa o turbo.
- [ ] Soltar o botão esquerdo desativa.
- [ ] Segurar Espaço ativa o turbo.
- [ ] Soltar Espaço desativa.
- [ ] O botão mobile ativa enquanto pressionado.
- [ ] Soltar o botão mobile desativa.
- [ ] Trocar de aba não deixa o turbo preso.
- [ ] Pausar não deixa o turbo preso.

## Velocidade e movimento

- [ ] A aceleração acontece gradualmente.
- [ ] A desaceleração acontece gradualmente.
- [ ] A velocidade aumenta visivelmente.
- [ ] A cobra ainda consegue virar.
- [ ] A curva fica levemente mais aberta no turbo.
- [ ] O corpo permanece suave.
- [ ] A câmera afasta durante o turbo.
- [ ] A câmera volta suavemente ao normal.

## Massa

- [ ] A massa diminui enquanto o turbo está ativo.
- [ ] A massa para de diminuir ao soltar.
- [ ] O turbo é bloqueado no limite mínimo.
- [ ] O botão mobile mostra bloqueio.
- [ ] O HUD mostra Sem massa.
- [ ] Os segmentos diminuem gradualmente ao perder massa.
- [ ] A espessura diminui gradualmente.

## Rastros

- [ ] O turbo deixa energia atrás da cauda.
- [ ] A energia não nasce na cabeça.
- [ ] A energia pode ser coletada depois.
- [ ] A energia recupera massa.
- [ ] A energia não aumenta pontuação.
- [ ] Coletar um rastro não cria comida natural extra.
- [ ] A quantidade de rastros aparece no diagnóstico.
- [ ] O pool reaproveita os rastros removidos.

## Efeitos

- [ ] O brilho aumenta durante o turbo.
- [ ] Segmentos dourados aparecem.
- [ ] Partículas aparecem na cauda.
- [ ] Linhas de movimento aparecem.
- [ ] A vinheta aparece.
- [ ] Os efeitos diminuem ao soltar.
- [ ] Qualidade baixa reduz os efeitos.
- [ ] Qualidade alta aumenta os efeitos.

## Interface e mobile

- [ ] O medidor de turbo aparece no HUD.
- [ ] O medidor muda para Ativo.
- [ ] O medidor muda para Sem massa.
- [ ] O botão ⚡ aparece apenas em dispositivo de toque.
- [ ] Joystick e botão ⚡ podem ser usados juntos.
- [ ] Seguir o toque e botão ⚡ podem ser usados juntos.
- [ ] A interface funciona na vertical.
- [ ] A interface funciona na horizontal.

## Regressão

- [ ] Comida comum continua funcionando.
- [ ] Comida especial continua funcionando.
- [ ] Pontuação continua correta.
- [ ] Crescimento continua correto.
- [ ] Pausa continua funcionando.
- [ ] Reinício zera massa, score, rastros e turbo.
- [ ] O console não mostra erros.
