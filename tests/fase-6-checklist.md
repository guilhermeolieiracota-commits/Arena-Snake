# Checklist de validação — Fase 6

## Proteção de nascimento

- [ ] O jogador nasce com escudo.
- [ ] O contador começa perto de 2,6 segundos.
- [ ] O escudo desaparece gradualmente.
- [ ] O jogador não morre durante a proteção.
- [ ] Bots nascem protegidos.
- [ ] Corpos protegidos não eliminam outras cobras.
- [ ] O respawn restaura a proteção.

## Cabeça contra corpo

- [ ] O jogador morre ao bater no corpo de um bot.
- [ ] O bot recebe a eliminação.
- [ ] Bots morrem ao bater no corpo do jogador.
- [ ] O jogador recebe a eliminação.
- [ ] Bots também eliminam outros bots.
- [ ] A própria cobra não colide com o próprio corpo.
- [ ] A colisão acompanha curvas e caudas corretamente.

## Cabeça contra cabeça

- [ ] Cobras parecidas morrem juntas.
- [ ] A cobra claramente maior sobrevive.
- [ ] O vencedor recebe uma eliminação.
- [ ] Choque equilibrado não concede eliminação.
- [ ] Proteção impede choque fatal.

## Borda

- [ ] A borda ainda apresenta aviso visual.
- [ ] O jogador morre após tocar a borda sem proteção.
- [ ] Bots podem morrer na borda.
- [ ] Bots mortos na borda entram em respawn.
- [ ] A tela mostra o motivo correto.

## Restos

- [ ] A cobra morta desaparece.
- [ ] O corpo vira restos luminosos.
- [ ] As cores combinam com a cobra.
- [ ] Os restos podem ser coletados.
- [ ] Os restos aumentam massa.
- [ ] Os restos aumentam pontuação.
- [ ] Muitas mortes não criam objetos infinitos.
- [ ] O diagnóstico mostra a quantidade de restos.

## Respawn dos bots

- [ ] Bot eliminado desaparece.
- [ ] O contador de bots ativos diminui temporariamente.
- [ ] Bot reaparece após pequeno intervalo.
- [ ] Bot reaparece em posição segura.
- [ ] Massa e score do bot são reiniciados.
- [ ] IA volta a funcionar.
- [ ] Turbo volta a funcionar.

## Ranking

- [ ] Ranking aparece durante a partida.
- [ ] Ranking ordena por massa.
- [ ] Jogador aparece destacado.
- [ ] A posição aparece no HUD.
- [ ] Ranking atualiza ao crescer.
- [ ] Ranking atualiza após mortes.
- [ ] Top 10 aparece no computador.
- [ ] Ranking fica compacto no celular.

## Feed e eliminações

- [ ] Feed mostra eliminações.
- [ ] Feed mostra mortes na borda.
- [ ] Feed desaparece após alguns segundos.
- [ ] Eliminações do jogador são contabilizadas.
- [ ] Reiniciar zera eliminações.

## Tela de derrota

- [ ] Tela aparece quando o jogador morre.
- [ ] Motivo da morte está correto.
- [ ] Score final está correto.
- [ ] Maior massa está correta.
- [ ] Eliminações estão corretas.
- [ ] Posição final está correta.
- [ ] Tempo está correto.
- [ ] Jogar novamente funciona.
- [ ] Voltar ao menu funciona.

## Desempenho e regressão

- [ ] F3 mostra corpos e células da colisão.
- [ ] F3 mostra mortes e restos.
- [ ] Comida continua funcionando.
- [ ] Crescimento continua funcionando.
- [ ] Turbo continua funcionando.
- [ ] IA continua funcionando.
- [ ] Pausa congela toda a arena.
- [ ] Trocar de aba pausa corretamente.
- [ ] O console não mostra erros.
